This is respository is for building a website for a premium gym called FitLat based in Islamabad. It is a responsive website that is built with ReactJS, Tailwind and TypeScript.

## Features
- Responsive design
- Contact form
- Class schedule
- Testimonials
- Gallery

## Installation
1. Clone the repository
2. Open index.html in your browser
